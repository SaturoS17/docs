---
title: "Comisiones"
description: "Configura los precios de tu organización por servicio, país y cuenta"
---

Tú decides cuánto cobra tu organización a sus clientes. Cada configuración
es una combinación de **servicio + país + activo** con dos componentes que
se suman: `percent` y `fixed_amount` (cualquiera puede ser `"0"`).

## Servicios configurables

| `service` | Cobra sobre |
|---|---|
| `payout` | El monto USDT de cada payout |
| `payin` | El USDT bruto de cada cobro recibido |
| `funding` | Cada depósito crypto acreditado |
| `withdrawal` | Cada retiro on-chain |
| `compliance_person` | Cada screening KYC de persona (solo fijo) |
| `compliance_company` | Cada screening KYC de empresa (solo fijo) |
| `compliance_rescreen` | Cada rescreening (solo fijo) |
| `compliance_transaction` | Cada screening de transacción (solo fijo) |
| `compliance_monitoring` | Cada activación de monitoreo (solo fijo) |

## Dos niveles: default y override

1. **Default de la organización** (`PUT /v1/org/fees`): aplica a todas las
   cuentas.
2. **Override por cuenta** (`PUT /v1/accounts/{id}/fees`): gana sobre el
   default para esa cuenta.

La resolución es de lo más específico a lo más general:
override de cuenta con país exacto → override de cuenta sin país → default
con país exacto → default sin país → **0**.

## Ejemplos

```bash
# Default: payout Chile 1.5% + 0.30 USDT para toda la organización
curl -X PUT https://exchange.qbank.cl/platform/v1/org/fees \
  -H "Authorization: Bearer pk_…" \
  -d '{
    "service": "payout",
    "country": "CL",
    "percent": "1.5",
    "fixed_amount": "0.30"
  }'

# Default sin país (fallback para el resto de países)
curl -X PUT https://exchange.qbank.cl/platform/v1/org/fees \
  -H "Authorization: Bearer pk_…" \
  -d '{ "service": "payout", "percent": "2.0" }'

# Override VIP: a este cliente el payout CL le cuesta 0.8% sin fijo
curl -X PUT https://exchange.qbank.cl/platform/v1/accounts/{accountID}/fees \
  -H "Authorization: Bearer pk_…" \
  -d '{ "service": "payout", "country": "CL", "percent": "0.8" }'

# KYC de empresa: 5 USDT fijo por screening
curl -X PUT https://exchange.qbank.cl/platform/v1/org/fees \
  -H "Authorization: Bearer pk_…" \
  -d '{ "service": "compliance_company", "fixed_amount": "5.00" }'
```

Consulta lo configurado:

```bash
curl https://exchange.qbank.cl/platform/v1/org/fees -H "Authorization: Bearer pk_…"
curl https://exchange.qbank.cl/platform/v1/accounts/{accountID}/fees -H "Authorization: Bearer pk_…"
```

## Tu revenue

Cada comisión cobrada se acredita como asiento auditable. Tu parte (lo
cobrado a tus clientes menos el costo de plataforma) se acumula en tu cuenta
de revenue:

```bash
curl https://exchange.qbank.cl/platform/v1/org/revenue \
  -H "Authorization: Bearer pk_…"
```

```json
{ "org_id": "…", "asset": "USDT", "revenue": "1250.375000" }
```

<Note>
Los clientes ven sus comisiones efectivas en `GET /v1/rates`, así que los
cambios de precios son transparentes e inmediatos.
</Note>
