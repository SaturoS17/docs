Tu saldo USDT puede fondearse y retirarse directamente on-chain. Redes
soportadas: **TRON** (`tron`) y **Ethereum** (`eth`), activo **USDT**.

## Crear tu wallet

Cada cuenta tiene una **wallet on-chain propia por red** (una en TRON, una en
Ethereum). La wallet se crea automáticamente la **primera vez** que pides tu
dirección de depósito en esa red; desde entonces la dirección es tuya,
estable y reutilizable.

```bash
curl "https://exchange.qbank.cl/platform/v1/crypto/deposit-address?chain=tron" \
  -H "Authorization: Bearer <token>"
```

- **Primera llamada en la red** → crea la wallet y devuelve `201` con la
  dirección. Si tu operador configuró la comisión `wallet_creation`, se
  cobra aquí (fijo por wallet; la respuesta lo informa en `creation_fee` y
  se reembolsa automáticamente si la creación falla).
- **Llamadas siguientes** → devuelven `200` con la misma dirección, siempre
  gratis.

```json
{
  "chain": "tron",
  "asset": "USDT",
  "address": "TQmZ…",
  "created_at": "2026-07-06T20:00:00Z",
  "creation_fee": "0.000000"
}
```

Con saldo insuficiente para la comisión de creación recibes
`402 insufficient_funds`.

## Fondeo (depósitos)

### 1. Envía USDT a la dirección de tu wallet

<Warning>
Envía **solo USDT por la red correcta** a la dirección de tu wallet. La
dirección es tuya y estable: puedes reutilizarla para todos tus depósitos.
</Warning>

### 2. Recibe el abono automático

Cuando el depósito se confirma on-chain, tu saldo se acredita
automáticamente (neto de la comisión de `funding` si tu operador la
configuró) y se emite el webhook `crypto_deposit_credited`:

```json
{
  "account_id": "…",
  "chain": "tron",
  "asset": "USDT",
  "tx_id": "b1946ac9…",
  "amount": "499.000000",
  "fee": "1.000000"
}
```

## Retiros

### Crear un retiro

```bash
curl -X POST https://exchange.qbank.cl/platform/v1/crypto/withdrawals \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "chain": "tron",
    "to_address": "TVJ6…",
    "amount": "100.000000",
    "idempotency_key": "retiro-2026-07-06-b"
  }'
```

Respuesta `202` — se debita `amount + fee` y la transacción se transmite:

```json
{
  "withdrawal_id": "5e8c…",
  "chain": "tron",
  "asset": "USDT",
  "to_address": "TVJ6…",
  "amount": "100.000000",
  "fee": "1.000000",
  "total_debit": "101.000000",
  "status": "processing",
  "tx_id": "…"
}
```

### Estado final

Llega por el webhook `crypto_withdrawal_status_changed`:

- **`completed`**: confirmado on-chain; el `tx_id` es tu comprobante.
- **`failed`**: se reembolsa el débito completo (`withdrawal_refund`).

Historial completo de actividad on-chain (depósitos + retiros):

```bash
curl https://exchange.qbank.cl/platform/v1/crypto/transactions \
  -H "Authorization: Bearer <token>"
```

## Errores

| HTTP | `error` | Causa |
|---|---|---|
| 400 | `invalid_chain` | Red no soportada (usa `tron` o `eth`) |
| 400 | `to_address_required` | Falta la dirección destino |
| 402 | `insufficient_funds` | Saldo insuficiente para `amount + fee` |
| 422 | (retiro con `status: failed`) | Rechazado al transmitir; débito reembolsado |
| 503 | `withdrawals_unavailable` | Retiros no habilitados aún para este corredor |
