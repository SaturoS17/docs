---
title: "Fees"
description: "Configure your organization's pricing per service, country and account"
---

You decide what your organization charges its clients. Each configuration is
a combination of **service + country + asset** with two components that are
added: `percent` and `fixed_amount` (either can be `"0"`).

## Configurable services

| `service` | Charges over |
|---|---|
| `payout` | The USDT amount of each payout |
| `payin` | The gross USDT of each collection received |
| `funding` | Each credited crypto deposit |
| `withdrawal` | Each on-chain withdrawal |
| `compliance_person` | Each person KYC screening (fixed only) |
| `compliance_company` | Each company KYC screening (fixed only) |
| `compliance_rescreen` | Each rescreening (fixed only) |
| `compliance_transaction` | Each transaction screening (fixed only) |
| `compliance_monitoring` | Each monitoring activation (fixed only) |

## Two levels: default and override

1. **Organization default** (`PUT /v1/org/fees`): applies to every account.
2. **Per-account override** (`PUT /v1/accounts/{id}/fees`): beats the
   default for that account.

Resolution goes from most specific to most general:
account override with exact country → account override without country →
default with exact country → default without country → **0**.

## Examples

```bash
# Default: Chile payout 1.5% + 0.30 USDT for the whole organization
curl -X PUT https://exchange.qbank.cl/platform/v1/org/fees \
  -H "Authorization: Bearer pk_…" \
  -d '{
    "service": "payout",
    "country": "CL",
    "percent": "1.5",
    "fixed_amount": "0.30"
  }'

# Country-less default (fallback for every other country)
curl -X PUT https://exchange.qbank.cl/platform/v1/org/fees \
  -H "Authorization: Bearer pk_…" \
  -d '{ "service": "payout", "percent": "2.0" }'

# VIP override: this client pays 0.8% with no fixed part on CL payouts
curl -X PUT https://exchange.qbank.cl/platform/v1/accounts/{accountID}/fees \
  -H "Authorization: Bearer pk_…" \
  -d '{ "service": "payout", "country": "CL", "percent": "0.8" }'

# Company KYC: 5 USDT flat per screening
curl -X PUT https://exchange.qbank.cl/platform/v1/org/fees \
  -H "Authorization: Bearer pk_…" \
  -d '{ "service": "compliance_company", "fixed_amount": "5.00" }'
```

Check what's configured:

```bash
curl https://exchange.qbank.cl/platform/v1/org/fees -H "Authorization: Bearer pk_…"
curl https://exchange.qbank.cl/platform/v1/accounts/{accountID}/fees -H "Authorization: Bearer pk_…"
```

## Your revenue

Every collected fee is credited as an auditable ledger entry. Your share
(what you charge your clients minus the platform's cost) accumulates in your
revenue account:

```bash
curl https://exchange.qbank.cl/platform/v1/org/revenue \
  -H "Authorization: Bearer pk_…"
```

```json
{ "org_id": "…", "asset": "USDT", "revenue": "1250.375000" }
```

<Note>
Clients see their effective fees in `GET /v1/rates`, so pricing changes are
transparent and immediate.
</Note>
